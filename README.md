# 国道走破 — フェーズ1 UIプロトタイプ

iPhone専用のSwiftUIアプリです。外部データやネットワークを使わず、`DemoStore` 内のデモデータで以下を確認できます。

- ホーム: 全国走破率、走破マップ、最近のドライブ
- 記録: GPS記録中の状態、距離・時間・国道、停止／再開ボタン
- 国道詳細: 進捗、高低図、走破色、Appleマップへの案内
- 履歴詳細: タイトル、メモ、複数タグ、距離・時間、写真枠

## 開き方

macOS上で `KokudoShoha.xcodeproj` をXcode 15以降で開き、iPhoneシミュレータまたは実機を選んで実行してください。デプロイ対象はiOS 17.0です。

## フェーズ1の実装方針

画面用のサンプルデータは `DemoStore` に切り出し、`Drive` と `Route` は将来の永続化・iCloud同期・GPSの道路照合結果を載せ替えられる独立モデルにしています。地図は現在、オフラインでも表示できるSwiftUI Canvasのデモ描画です。実地図、GPS権限、道路データ照合、写真ライブラリ、オフライン地図の実装は次段階の対象です。
